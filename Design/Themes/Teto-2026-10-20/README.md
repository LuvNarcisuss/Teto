# Teto visual directions

The earlier lowercase-t/ribbon app icon and its provenance in this folder are historical. The active user-selected Rhythm t identity, runtime asset mapping and generation prompts are in `Design/Brand/Teto-Rhythm-2026-10-20/`. The intermediate dancing-person identity is also historical.

- `a-neon-stage.png`: Neon Stage.
- `b-selected-original.png`: user-selected original Fresh Studio board.
- `b-fresh-studio.png`: adjusted Fresh Studio board.
- `c-street-rhythm.png`: Street Rhythm.
- `d-soft-groove.png`: Soft Groove.

The selected direction is B / Fresh Studio. These are conceptual design boards, not captured app screens. Later requirements supersede pictured features: the implemented wallet uses diamonds only, with no Coins tab. Provider logos, illustrated balances and social counts are not evidence of connected services.

`prompts.json` records board generation instructions; `hero-provenance.json` records the separately generated runtime dance photograph. Boards remain outside the app target. Implementation details and runtime replacement points: `docs/fresh-studio-theme.md` at the project root.
