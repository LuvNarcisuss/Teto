# Phrases Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Phrases tab whose cards let a dancer read, count, learn, keep, branch, and share an eight-count phrase on this device.

**Architecture:** Built-in phrases stay in a catalog. Phrases written on this device, keep order, and learned marks live in an optional `phraseBook` on `LocalLibrary`, saved by the existing atomic library write. `AppStore` exposes one phrase API. UIKit screens under `Teto/Features/Phrases/` render the list, the open card, and the editor. The click is a local timer plus a short generated tone, stopped when the page leaves.

**Tech Stack:** UIKit, Swift 5, iOS 17, AVFoundation for the click, existing `AppStore.commit` and `CreationValidation.isEnglish`.

**Spec:** `docs/superpowers/specs/2026-10-22-phrases-design.md`

## Global Constraints

- UIKit and Swift 5, iOS 17 or newer. No SwiftUI, `UIHostingController`, or Objective-C source.
- Every new visible string is English, including titles, buttons, errors, empty states, and accessibility labels.
- Do not use demo, sample, mock, showcase, prototype, or the same idea in other words. Built-in phrases are catalog phrases.
- The app icon for the tab is a generated transparent bitmap loaded through `TetoIcon`. Do not use an SF Symbol.
- `LocalLibrary.schemaVersion` stays 1. `phraseBook` is optional so an older `library-v1.json` still decodes.
- Reports, blocks, keeps, learned marks, and shared chat lines stay on this device. Do not show a delivery, a public count, or a successful upload.
- Block and hide by creator id. Do not match a phrase author to a video by display name.
- Diamonds, gifts, and video playback are outside this feature.
- Verification is static source and resource inspection. Do not compile, launch the app, start a simulator, or run tests unless the user asks.
- After new files exist, sync the Xcode project with `xcodegen generate --spec project.yml --project . --no-env`. That command updates project metadata. It is not an app build.
- Shorts stays inside Live. The dock order is Live, Phrases, Voice, Chats, Me.

## Review Focus

- An older library file with no `phraseBook` key still decodes, and the Phrases tab shows the seven catalog phrases.
- A branch whose trimmed counts match its parent is refused, and the editor stays open.
- An empty count, a Chinese count, or a 49-character count is refused with the English validation sentence.
- A reported phrase and a phrase by a blocked author disappear from Kept, Yours, and the catalog group, and return when the report is removed or the author is unblocked.
- The click stops, and the idle timer is enabled again, when the page disappears or the app resigns active.

### Task 1: Phrase model and catalog

**Files:**
- Create: `Teto/Domain/DancePhrase.swift`
- Create: `Teto/Domain/DancePhraseCatalog.swift`

**Interfaces:**
- Consumes: `CreationValidation.isEnglish` in `Teto/Features/Creation/CreationSubmission.swift`
- Produces:
  - `enum PhraseStyle: String, Codable, CaseIterable` with `hipHop`, `kPop`, `jazz`, `freestyle`, `ballet`, `house`, `contemporary`, and `var title: String` returning `Hip-hop`, `K-pop`, `Jazz`, `Freestyle`, `Ballet`, `House`, `Contemporary`
  - `enum PhraseTempo: String, Codable, CaseIterable` with `slow`, `steady`, `quick`, titles `Slow`, `Steady`, `Quick`, and `var beatDuration: TimeInterval` of `1`, `0.75`, `0.6`
  - `struct DancePhrase: Codable, Equatable, Identifiable` with `id: String`, `title: String`, `style: PhraseStyle`, `tempo: PhraseTempo`, `eights: [[String]]`, `authorID: String`, `authorName: String`, `parentID: String?`, `parentTitle: String?`, `changedEights: [Int]?`, `createdAt: Date`
  - `enum PhraseText { static let validation = "Use an English title of up to 40 characters and an English count of up to 48 characters."; static let sameAsParent = "Change at least one count, or leave this phrase as it is." }`
  - `DancePhrase.validate(title:eights:) -> String?` returns `PhraseText.validation` or nil
  - `DancePhrase.changedEightIndexes(from:to:) -> [Int]` returns 1-based indexes whose trimmed lines differ
  - `DancePhraseCatalog.phrases: [DancePhrase]` with the seven ids, titles, styles, tempos, authors, and counts in the spec

- [ ] **Step 1: Add the types and the pure functions**

Trim title and counts before measuring length. A phrase is valid only when the title is non-empty, the title count is at most 40, there are 1 to 4 eights, every eight has exactly 8 lines, every line is non-empty and at most 48 characters, and `CreationValidation.isEnglish` accepts the title and every line.

`changedEightIndexes` compares by trimmed lines. A missing counterpart counts as changed. Return indexes in ascending order. An identical phrase returns an empty array.

- [ ] **Step 2: Write the catalog from the spec**

Use stable ids from the spec table. Set `parentID`, `parentTitle`, and `changedEights` to nil. Use one fixed `createdAt` for every catalog phrase so the list order does not depend on the clock. Author ids are `maya`, `maya`, `zoe`, `leo`, `noah`, `aria`, and `finn` in table order.

- [ ] **Step 3: Static check**

Confirm the seven ids are unique, each eight has eight non-empty English lines from the spec, and `beatDuration` is `1`, `0.75`, and `0.6`. Confirm no catalog string contains Chinese or a forbidden staging word.

### Task 2: Persist the phrase book

- Modify: `Teto/Domain/LocalLibrary.swift`

- Create: `Teto/Domain/PhraseBook.swift`

**Interfaces:**
- Consumes: `DancePhrase`, `DancePhraseCatalog.phrases`
- Produces:

  - `LocalLibrary.phraseBook: PhraseBookState?`
  - `PhraseBookState.normalized(catalogIDs: Set<String>) -> PhraseBookState` drops unknown keep ids and learned keys, and drops learned entries whose bool count does not match that phrase
  - `PhraseBookState.validationError(catalogIDs: Set<String>) -> String?`

- [ ] **Step 1: Add the optional field**

Add `var phraseBook: PhraseBookState? = nil` beside the other optional library fields. Leave `schemaVersion` at 1.

- [ ] **Step 2: Validate stored phrases without rejecting an older file**

`load()` keeps the current `schemaVersion == 1` check. A missing `phraseBook` is valid. When the field exists, reject the library with `LocalLibraryError.unreadableLibrary` if any stored phrase fails `DancePhrase.validate`, if a stored id is duplicated, or if a stored id equals a catalog id. A keep id or learned key that points at nothing is ignored by `normalized`, not a reason to fail the library. Do not write the file during `load()`.

- [ ] **Step 3: Static check**

Confirm `schemaVersion` is still assigned `1`, `phraseBook` is optional, and the new failure path is the existing `unreadableLibrary` error. Confirm catalog phrases are not required to be present in the JSON.

### Task 3: AppStore phrase API

**Files:**
- Create: `Teto/App/AppStore+Phrases.swift`

**Interfaces:**
- Consumes: `commit(_:)`, `library`, `isLoaded`, `isBusy`, `lastSaveError`, `PhraseBookState`, `DancePhraseCatalog`
- Produces:
  - `struct PhraseFeed { var kept: [DancePhrase]; var yours: [DancePhrase]; var catalog: [DancePhrase] }`
  - `func phraseFeed() -> PhraseFeed`
  - `func phrase(id: String) -> DancePhrase?`
  - `func visibleBranches(of parentID: String) -> [DancePhrase]`
  - `func hidesPhrase(_ phrase: DancePhrase) -> Bool`
  - `func savePhrase(_ phrase: DancePhrase) async -> Bool`
  - `func deletePhrase(id: String) async -> Bool`
  - `func toggleKept(id: String) async -> Bool`
  - `func toggleLearned(id: String, eightIndex: Int) async -> Bool`

- [ ] **Step 1: Resolve one visible collection**

A phrase is hidden when `isContentReported(id, kind: .phrase)` or `isCreatorBlocked(authorID)`. Catalog phrases come from `DancePhraseCatalog`. Device phrases come from `phraseBook?.phrases`. Display name for `authorID == "local-owner"` is `library.profile.displayName`.

`phraseFeed` places kept phrases first, in `keptOrder`, skipping hidden and unknown ids. Yours is device phrases not already kept, newest `createdAt` first. Catalog is the catalog order, skipping kept and hidden phrases. Each id appears once.

`visibleBranches` returns visible device phrases whose `parentID` equals the argument.

- [ ] **Step 2: Save, delete, keep, and learn through `commit`**

`savePhrase` refuses a catalog id, an invalid phrase, and a branch whose `changedEightIndexes` is empty. On the empty-diff refusal, set `lastSaveError` to `PhraseText.sameAsParent` and return false. On invalid text, set `lastSaveError` to `PhraseText.validation`. A successful branch stores the computed `changedEights`. Replacing a phrase clears the learned mark of each changed eight, drops marks for removed eights, and appends `false` for a new eight.

`deletePhrase` removes a device phrase and its keep and learned entries. It does not remove phrases that point at it. It returns false for a catalog id.

`toggleKept` inserts the id at the front of `keptOrder` or removes it. `toggleLearned` flips one zero-based eight index and stores a bool array whose count equals the eight count. Unknown ids and out-of-range indexes return false.

Every success uses the existing `commit` path. A failed commit leaves the in-memory library unchanged.

- [ ] **Step 3: Static check**

Confirm the API names above exist, catalog ids cannot be deleted, and `local-owner` display uses the profile name. Confirm no phrase method writes a video, a room, or a diamond balance.

### Task 5: Click

**Files:**
- Create: `Teto/Features/Phrases/PhrasePulse.swift`

**Interfaces:**
- Consumes: `PhraseTempo.beatDuration`
- Produces:
  - `struct PhraseBeat { var eightIndex: Int; var count: Int; var pickup: Int? }`
  - `final class PhrasePulse` with `play(tempo:eights:startEight:loopOneEight:onBeat:onClickFailed:)`, `stop()`, and `var isPlaying: Bool`
  - `onBeat` receives the beat to highlight. `pickup` is 5, 6, 7, or 8 only during the opening preparation. `count` is 1 through 8.

- [ ] **Step 1: Time the two play modes**

Use a main-queue timer. `loopOneEight == true` prepares once, then repeats counts 1...8 of `startEight`. `loopOneEight == false` prepares once, then plays eight `startEight` through the last eight and stops on count 8. There is no gap and no second preparation between counts or eights.

`stop()` invalidates the timer, ends the audio, and sets `UIApplication.shared.isIdleTimerDisabled = false`. `play` sets the idle timer disabled. `deinit` calls `stop()`.

- [ ] **Step 2: Make a short click**

Use `AVAudioEngine` and `AVAudioSession` category `.ambient` with `.mixWithOthers`. Beat 1 uses a higher, louder tone than the other beats. If the session or engine cannot start, call `onClickFailed` once and keep emitting `onBeat`. Do not throw over the page.

- [ ] **Step 3: Static check**

Confirm both modes are represented in `play`, preparation values are only 5, 6, 7, and 8, and every exit path calls `stop()` or re-enables the idle timer.
