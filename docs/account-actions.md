# 设置中的账号操作

Account 区域提供 Log out 与 Delete account，均需要用户确认。退出只结束本地会话、暂停历史与短视频写入并返回登录页，保留磁盘资料。

删除只针对当前沙盒 Application Support/Teto。包括资料库、导入视频副本、聊天、草稿、关注、点赞/收藏、评论/回复、举报/屏蔽及浏览记录、协议同意记录。相册原文件和应用内置资源不受影响。钱包当前没有持久化余额或真实购买服务，仅重置内存状态。界面明确没有远端账号删除。

操作需等待现有保存/钱包请求完成；结束会话后拒绝界面退出时的延迟写入。浏览历史 actor 暂停后再删除，短视频保存入口同时关闭。删除前在 Application Support 写入专用持久化标记，清除 Teto 目录后建立空资料库，最后移除标记。若中断或失败，下次 load 会先完成清理；失败时阻止进入主页，保留 Try again 重试。建立空 Teto 目录避免旧版迁移重新恢复已删资料。

未执行实际数据删除、编译、运行或测试。源码审查涵盖取消、保存中禁用、删除失败、重启恢复与退出后重新登录路径；真机界面、失败注入和重启结果仍未验证。
