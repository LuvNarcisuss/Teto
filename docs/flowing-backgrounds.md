# 流动背景

页面背景由 FreshStudioPageBackground 统一绘制：奶白/薄荷底色、青绿与浅青柠径向光晕、两条相反方向的比例曲线以及细亮边。使用原生 SwiftUI Shape 与 Gradient，无新增图片或外部依赖。

覆盖 Live 浏览、Voice、Chats、Me、作者主页、搜索结果和采用 freshStudioPage 的钱包、表单、设置、评论等面板。顶部栏和输入区使用同色系柔和渐变；聊天行用轻白底透出整体背景。作者资料及钱包余额区使用独立轻量装饰。

直播/短视频播放背景、摄像头、欢迎和登录的舞蹈照片保留。装饰禁用命中与无障碍读取，无计时器或持续动画；提高对比度时弱化背景纹理。当前图标与艺术字保持不变。

仅检查源码，未编译、运行、启动模拟器或执行测试。最终设备上的对比度、安全区和大字体排版仍待确认。

## 顶部覆盖修正

Live 浏览页与 Me 页的背景位于 safeAreaInset 外层，并在填满容器后延伸至系统安全区。Live 内嵌列表关闭自己的背景，普通顶部栏透明；搜索期间保留列表状态但隐藏列表内容，搜索栏和结果也共用同一画布。独立收藏列表与其它搜索入口继续使用自己的默认背景。个人简介区移除 FreshStudioBackdrop，避免与页面曲线重叠产生拼接边界。Shorts 的视频层与系统底部导航未修改。仅静态检查，未编译或运行。
